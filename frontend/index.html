Document + Liveness Verification — Prototype

Demo build for internal review. not started

What this prototype actually proves, and what it doesn't: this demonstrates the OCR → active liveness challenge → face-match → decision pipeline end to end, running entirely on open-source components (OpenCV YuNet/SFace, Tesseract). It has no connection to any Bhutanese government registry, so it cannot confirm a document number is genuine or unrevoked — only that the image looks plausible. Liveness uses head-turn / smile challenges only (no blink detection in this build), and the anti-spoofing check is a soft heuristic, not a certified presentation-attack-detection model. Treat every score on this page as a demo of the mechanism, not a production accuracy claim.

    We'll walk you through a random sequence of actions on webcam — the randomness is what makes this harder to spoof with a pre-recorded video than a fixed script would be. Each action is counted in first and only recorded once the prompt says NOW, so take your time; the countdowns and the pauses between actions aren't scored. Budget about half a minute.
